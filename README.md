
# Institutional Learning Analytics Dashboard

## 📌 Project Overview
The Institutional Learning Analytics Dashboard is an interactive data analytics project developed using Microsoft Power BI. It focuses on analyzing student engagement, academic performance, module completion, and learning activities to generate meaningful insights.

## 🎯 Project Objectives
- Analyze student learning activities and engagement.
- Monitor module completion rates.
- Evaluate student assessment performance.
- Compare student activity across colleges and departments.
- Identify learning trends and performance patterns.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

## 📊 Key Performance Indicators (KPIs)
- Total Students: 100
- Average Assessment Score: 75.64
- Students Done: 33%
- Average Login Count: 41.15
- Students Above 80: 34

## 📈 Dashboard Features
- Module-wise completion analysis.
- College-wise login count analysis.
- Department-wise assessment score comparison.
- Student login trends over time.
- Student performance details.
- Interactive department and date slicers.
- KPI cards for monitoring key metrics.

## 🔍 Key Insights
- Analyzed student engagement through login activity.
- Compared assessment performance across departments.
- Evaluated module completion to understand learning progress.
- Identified students scoring above 80.
- Used interactive filters to explore student performance.
